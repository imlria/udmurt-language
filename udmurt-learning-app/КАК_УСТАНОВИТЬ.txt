Зеч-а бур-а удмурт кыл?
Приложение для изучения удмуртского языка (Android)

Папка
  Zech-a-bur-a-udmurt-kyl.apk  - само приложение
  установить.bat              - установка на телефон по USB с компьютера
  запустить.bat               - запуск уже установленного приложения
  platform-tools\             - adb (нужен скриптам установки)
  КАК_УСТАНОВИТЬ.txt          - эта инструкция

Требования
  • Телефон или планшет на Android 8.0 или новее
    (приложение - для Android, на Windows можно).
  • Для входа / регистрации нужен интернет (один раз).
    Словарь и картинки уже внутри приложения - дальше можно офлайн.

Способ 1. Самый простой — через файлы на телефоне
  1. Скопируйте файл Zech-a-bur-a-udmurt-kyl.apk на телефон
     (USB, Telegram, Google Drive, флешка - как удобно).
  2. На телефоне откройте этот файл.
  3. Если система спросит разрешение «Установка из неизвестных
     источников» / «Разрешить установку приложений» - разрешите.
  4. Нажмите «Установить», затем «Открыть».

Способ 2. С компьютера по USB (Windows)
  1. На телефоне включите «Параметры разработчика» и «Отладка по USB»:
       Настройки - О телефоне - 7 раз нажмите «Номер сборки»
       Затем: Параметры разработчика - Отладка по USB - ВКЛ.
  2. Подключите телефон кабелем к компьютеру.
     На экране телефона подтвердите «Разрешить отладку USB».
  3. На компьютере дважды щёлкните установить.bat
  4. Дождитесь сообщения «Готово». Затем можно нажать запустить.bat

Если установить.bat пишет «устройство не найдено»:
  • проверьте кабель / другой порт USB
  • подтвердите запрос отладки на экране телефона
  • в диспетчере устройств Windows не должно быть неизвестного устройства

После установки
  • Зарегистрируйтесь или войдите с интернетом).
  • Дальше уроки, игры и прогресс работают и без интернета.
  • Прогресс сохраняется на устройстве и синхронизируется при сети.
